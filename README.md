# Global Superstore Sales Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed using Global Superstore data to analyze sales performance, profitability, targets, returns, delivery performance, and overall business growth.

The dashboard converts raw business data into meaningful insights using data modeling, DAX measures, KPIs, and interactive visualizations.

---

## Project Objectives

- Analyze overall sales and profit performance
- Measure target achievement across categories
- Monitor returns and delivery efficiency
- Evaluate regional and manager performance
- Generate actionable business insights and recommendations

---

### Regional Insights
